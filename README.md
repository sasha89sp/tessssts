# Huawei E173 Manager

Приложение на Flutter для управления 3G/4G модемом Huawei E173 (и совместимыми) на Windows.

## Возможности
- Проверка баланса через USSD-запросы (с автоматической поддержкой кодировок UCS2 и GSM).
- Чтение, отправка и удаление SMS-сообщений.
- Автоматическое определение AT COM-порта модема.
- Сохранение истории SMS локально на устройстве (Hive).
- Поддержка тёмной и светлой темы.
- Портативная сборка (Portable ZIP) без необходимости установки через GitHub Actions.
